# Guide

This docs site is built with [Undocs](https://github.com/unjs/undocs).

## Local development

Install dependencies from this folder:

```bash
pnpm install
```

Run the docs site locally:

```bash
pnpm dev
```

## Production build

Generate the static docs output:

```bash
pnpm build
```

Undocs writes the generated static site to `.docs/.output/public`.
